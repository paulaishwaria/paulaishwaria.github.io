# Paula Aishwaria — Portfolio website

This is a starter portfolio website for GitHub Pages.

## Publish
1. Open the repository `paulaishwaria.github.io`.
2. Choose **Add file → Upload files**.
3. Upload `index.html` and `styles.css` from this folder (not the ZIP itself).
4. Commit the changes to the `main` branch.
5. Visit `https://paulaishwaria.github.io` after GitHub Pages finishes deploying.

## Before sharing publicly
- LinkedIn and email links are personalised. Check them before publishing.
- Review every project description for accuracy.
- Keep company-confidential information, internal screenshots, customer details and proprietary data out of the public repository.

The site intentionally avoids invented performance metrics. Add quantified outcomes only when you can verify and safely disclose them.
